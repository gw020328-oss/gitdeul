# 깃들 데모 내용 자료

`demo/CONTRACT.md`의 모양을 따른 자료다. 게임 코드는 없다. 점검은 아래 명령으로 한다.

```bash
python3 -I demo_content/check_content.py
```

## 파일

| 파일 | 내용 |
|---|---|
| `zones.json` | 네 구역의 칸, 아이템, 벌이 세 갈래, 불청객, 고민, AI가 말해 주는 범위. 맨 끝에 불청객 5종 목록(`intruders`) |
| `species.json` | 이웃 36종 |
| `news.json` | 오늘의 소식 23개 |
| `check_content.py` | 이름표와 칸 id, 금지어를 확인하는 스크립트 |

## 어디서 가져왔나

- 구역, 칸, 아이템, 벌이, 불청객: 1차 기획서 7, 8장과 기획서 8, 9, 11장. 값의 단계(조금, 보통, 많이)는 기획서 8.3.
- 이웃의 자리, 갈래: CONTRACT의 이름표 그대로.
- 좋아하는 칸과 꺼리는 칸: 기획서 11장의 칸 표. 종에 직접 적힌 것만 출처를 달았다.
- 세 단계의 몸짓: 기획서 5.5와 설계안 7.6. 문서에 없는 종은 "모든 종의 틀"(기획서 5.5)을 쓰고 깃듦만 짐작으로 채웠다.
- 실제 이야기: 행동_문헌조사의 글과 출처 주소.
- 표지: 두 CSV에서 종 이름으로 찾았다. `badgeDetail`에 번호와 등급이 있다.
- 학명: 멸종위기종 CSV에 있는 것만 `sciChecked: true`. 나머지는 일반 지식으로 적은 것이라 확인이 필요하다.

## 모든 항목에 붙은 출처 표시

- `from` 또는 `...From`: 출처가 문서 이름과 장이다. 문서에 없으면 `"짐작"`이다.
- `story.checked`: 이야기의 모든 문장이 출처 주소나 CSV로 받쳐질 때만 true. 문서에는 있지만 출처 주소가 없는 글(조사 비율 같은 것)은 false다.
- `story.thin`: 실제 이야기가 한두 줄뿐이다. 어디에 사는지, 왜 줄었는지, 어디서 볼 수 있는지를 더 찾아야 한다.

## CONTRACT보다 더한 항목

게임 쪽에서 읽지 않아도 된다. 읽으려면 아래를 참고한다.

- 칸: `from`, `earns`(돈 되는 칸이면 true), `fixed`(집). 집의 `costLevel`은 null이다.
- 아이템: `costLevel`(보통), `from`, `placeOnGuess`(놓는 곳을 짐작으로 둔 것). `placeOn`의 `"*"`는 아무 칸이다.
- 구역: `aiSays`, `hardReason`, `title`(칭호), `expandCost`, `evidence`.
- 냇가의 `intruder`는 배스이고 `also`에 블루길이 있다.
- 종: `sciChecked`, `badgeDetail`, `badgesNote`, `dayPartFrom`, `hiddenFrom`, `basisFrom`, `itemLikes`(물꼬처럼 칸이 아닌 아이템이 좋은 경우), `stagesFrom`, `seasonMismatch`, `tracesFrom`.
- `itemLikes`의 `item`은 그 구역의 아이템 id이거나 작은 벌이 id(`clam`)다.
- 소식: `from`. 예시 `footprint`는 CONTRACT 예시와 달리 `zone`을 `field`로 했다. 문장에 논둑이 있어서다.
- 어름치의 흔적 `tower`(돌탑)는 CONTRACT의 세 가지 밖이다. 기획서 4.4에 있다.

## 짐작으로 채운 곳

수는 스크립트로 센 것이다.

| 항목 | 짐작 수 |
|---|---|
| 좋아하는 칸 | 27 |
| 꺼리는 칸 | 13 |
| 단계의 몸짓(36종 곱하기 3) | 31 |
| 만나는 때(`dayPart`) | 25종 |
| 흔적의 배정 | 32종 |
| 판단 근거(`basis`)의 종별 확인 | 4종 (청설모, 멧토끼, 넓적부리도요, 왜가리) |
| 소식이 뜨는 때 | 14개 |
| 실제 이야기가 확인되지 않은 종(`checked: false`) | 19종 |
| 그중 "아직 찾지 못했다"로 시작하는 종 | 5종 (청둥오리, 노루, 청설모, 멧토끼, 왜가리. 노루는 조사 지점 수만 덧붙임) |

짐작은 가볍게만 채웠다. 숫자는 넣지 않았다. 글 속의 퍼센트는 기획서의 조사 결과를 옮긴 것이다.

## 확인이 필요한 곳

표지

- 어름치: 문서는 멸종위기 2급이라 하나 멸종위기종 CSV(2024-12-31)에서 찾지 못했다. `badgesChecked: false`로 두고 천연기념물만 넣었다.
- 두루미, 황조롱이, 수달: 천연기념물 CSV에서 번호가 비어 있다.
- 점박이물범: 멸종위기종 CSV에는 `물범`(Phoca largha)으로 올라 있다. 학명으로 맞췄다.
- 쏘가리, 노루, 농게, 다람쥐: 비슷한 이름(황쏘가리, 사향노루, 흰발농게, 하늘다람쥐)만 목록에 있다. 표지는 없다.
- 큰기러기: 멸종위기 II급만 있고 천연기념물은 아니다.
- 표지가 비어 있는 종은 두 목록에서 이름으로 찾아도 없다는 뜻이다. 이 경우도 `badgesChecked: true`다.

단계의 몸짓

- 큰고니의 깃듦: 문서는 "다시 찾는 중"이다. 짐작 문장을 넣었다.
- 원앙의 깃듦(무리가 된다)은 겨울의 모습이다. 다람쥐의 깃듦(도토리를 나른다)은 가을의 모습이다. 철이 맞지 않아 `seasonMismatch`로 표시했다.
- 물고기와 원앙의 경계 행동은 기록이 거의 없다. 물고기의 들름은 연출이다.

이야기

- 하늘다람쥐: 둥지 상자를 쓰는 비율이 낮다는 연구는 검색 요약만 봤다. 원문 확인이 필요하다.
- 솔부엉이: 출처 주소가 문서에 없다. 우는 철과 시간의 국내 수치도 못 찾았다.
- 큰기러기: 기러기류 전체를 기준으로 한 글을 가져왔다. 맞는지 확인해야 한다.
- 황조롱이: 출처가 영국 자료다. 한국 기록을 따로 찾아야 한다.
- 달랑게와 점박이물범: 해양보호생물인지 확인한다(설계안 2.4).
- 바닷가 종: 풀과 게의 이야기는 기획서의 조사 비율뿐이다. 바닷가 이웃의 행동은 문헌을 아직 찾지 않았다(설계안 7.6).
- 어려운 발길 가운데 출처 주소가 있는 이야기는 두루미, 황새, 큰고니, 어름치, 수달, 산양, 하늘다람쥐다. 감돌고기는 한 줄뿐이고, 달랑게, 넓적부리도요, 점박이물범은 주소가 없다.
- 잦은 발길과 뜸한 발길의 이야기는 대부분 얇다.

판단 근거

- 수달은 모델이 약해서 문헌으로 받친다(기획서 11.2). 계약에 `model`만 있어 `model`로 두었다.
- 산양, 하늘다람쥐, 점박이물범은 `literature`다. 넓적부리도요도 짐작으로 `literature`에 두었다.
- 나머지 종의 `model`은 구역의 근거 자료가 있다는 뜻이다. 종마다 모델이 만들어졌는지는 확인하지 않았다.

칸과 아이템

- 아이템의 놓는 곳 중 `bankgrass`, `nestbox`, `sandfence`는 짐작이다.
- 가림막은 문서에 "길이나 집 쪽"이라 적혀 있는데 길 칸이 없어 집으로 두었다.
- 논밭, 풀밭·벤 자리, 마을의 `costLevel`은 기획서 8.3을 옮기거나 짐작한 값이다.
- 쉴 자리 마련하기를 구역마다 무엇으로 할지는 1차 기획서 16장이 아직 정하지 않았다. 아이템에 넣지 않았다.
- 걷는 화면과 가꾸는 화면에 필요한 그림 이름, 소리 이름은 만들지 않았다.
