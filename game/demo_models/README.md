# 깃들 데모: 간단한 3D 모형

이웃 36종과 불청객 5종을 코드로만 그린 간단한 모형이다. 텍스처와 바깥 파일이 없다. 두루미, 황새, 큰고니의 움직이는 3D 모형이 따로 있어도, 이 모형은 모든 종에 쓸 수 있는 예비용이다.

## 파일

| 파일 | 내용 |
|---|---|
| `simple_models.js` | 모형 41개를 만드는 코드 한 파일 |
| `preview.html`, `preview.js` | 41개를 한 화면에 늘어놓는 미리보기 |
| `preview.png` | 옆에서 본 전체 (가만히) |
| `preview_top.png` | 위에서 본 전체 |
| `preview_feed.png` | 먹기 동작의 전체 |
| `preview_fly.png` | 새 8종이 나는 모습(위에서 비스듬히, 날갯짓 중 한 장면) |

## 쓰는 법

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js"></script>
<script src="demo_models/simple_models.js"></script>
```

```js
const m = GD_SIMPLE.make("crane", { stage: 2 });
scene.add(m.group);          // 발밑 가운데가 원점, 위가 +Y, 앞이 +Z, 1 단위 = 1 m
// 매 프레임
m.update(dt, t, "idle");     // mode: idle, feed, alert, move, rest, 그리고 새만 fly
```

- `GD_SIMPLE.ids`는 41개 id다. 이름표는 `demo/CONTRACT.md`와 같다.
- `make`가 돌려주는 것: `group`, `height`(키, m), `length`(앞뒤 길이), `width`(좌우 폭), `tris`(삼각형 수), `update(dt, t, mode)`, `dispose()`.
- `update`의 `dt`는 초 단위이고 0.1초를 넘으면 0.1초로 본다. `t`는 흐른 시간(초)이다. 모드를 바꾸면 자세가 부드럽게 바뀐다.
- 모든 모형이 재질 하나를 함께 쓴다(색은 꼭짓점 색). 같은 id를 여러 번 만들어도 모형끼리 서로 영향이 없다.
- 이동은 모형이 하지 않는다. `move`는 다리와 몸만 움직이고 `group`의 자리는 게임 쪽에서 옮긴다.
- 게임 쪽에서 더 크게 보이게 하려면 `group.scale`을 키우면 된다(모형 안쪽 크기는 건드리지 않는다).
- 쓰는 도구: `THREE.MeshStandardMaterial`(꼭짓점 색, 평평한 면). 게임의 색 처리와 맞추려고 색은 sRGB 값을 선형으로 바꿔 넣었다.

### 새가 날아가게 하기 (`fly`)

새 13종은 `update(dt, t, "fly")`를 부르면 날개를 옆으로 활짝 펴고 퍼덕인다. 목을 앞으로 뻗고(왜가리는 목을 접는다), 다리는 두루미, 황새, 왜가리, 저어새, 넓적부리도요는 뒤로 뻗고 나머지는 접는다. 다른 모드로 바꾸면 날개를 접고 다시 선다(0.3초쯤 걸려 부드럽게 바뀐다).

- 날개를 편 길이는 종마다 실제 값에 맞춘다(두루미 2.4 m, 황새 2.1 m, 큰고니 2.3 m, 큰기러기 1.6 m, 왜가리 1.7 m, 청둥오리 0.9 m, 황조롱이 0.75 m 등). 1초에 날갯짓하는 횟수도 크기에 맞춰 다르다(두루미 2번, 청둥오리 7번, 넓적부리도요 10번). 이 값은 모두 기억으로 정한 대략의 값이다. 확인 필요.
- 모형은 날 때 제 자리에서 날갯짓만 한다. 날아가는 방향과 높이는 게임 쪽에서 `group.position`을 옮겨 준다.
- 땅에서 떠 보이게 하려면 `m.flyLift = 높이(m)`로 정한다(`make(id, { flyLift: 1.2 })`로 처음에 줄 수도 있다). `fly`로 바뀌는 동안 그만큼 부드럽게 떠오르고, 다른 모드로 돌아오면 내려온다. 게임이 `group.position.y`를 직접 올릴 때는 0으로 두면 된다.
- 새가 아닌 모형에 `fly`를 주면 아무 동작도 하지 않고 가만히 있는다.
- 날개는 접힌 판을 펼쳐 만든 단순한 모양이다. 깃털 하나하나나 날개 끝이 갈라지는 모습은 없다.

### 풀과 자란 정도

풀 네 종(`reed`, `rugosa`, `suaeda`, `spartina`)은 `opts.stage` 1~3에 따라 모양이 다르다. 싹(1), 자람(2), 군락(3)이다.

- 칠면초는 자라면서 초록, 주황, 진한 붉은색으로 물든다(칠면초라는 이름의 뜻).
- 갈대는 3에서 이삭이 달리고, 해당화는 3에서 꽃과 붉은 열매가 달린다.
- 이미 만든 풀은 `m.setStage(n)`으로 단계를 바꿀 수 있다(모양을 새로 만든다). `m.stage`, `m.height`가 따라 바뀐다.
- 풀의 `height`는 지금 단계의 키다. 크기의 기준은 3단계다.
- 동물은 `stage`를 쓰지 않는다.
- 풀은 바람에 흔들린다. `alert`, `move`에서는 더 세게 흔들린다.

## 종마다 살린 특징

멀리서 실루엣과 색으로 가릴 수 있게 한 것들이다.

- 새: 두루미(붉은 정수리, 검은 목 윗부분과 날개 뒤쪽), 황새(굵고 곧은 검은 부리, 붉은 다리, 눈 둘레의 붉은 살), 큰고니(긴 S자 목, 부리 밑동의 노란 쐐기), 저어새(검고 긴 주걱 부리, 검은 얼굴), 넓적부리도요(작은 몸, 끝이 넓은 부리), 왜가리(회색 등, 흰 목, 검은 댕기, 노란 부리), 원앙(주황 은행잎 모양 날개깃, 붉은 부리, 흰 눈썹줄), 청둥오리(녹색 머리, 흰 목테), 쇠기러기(흰 이마), 큰기러기(검은 부리의 주황 띠), 황조롱이(갈고리 부리, 긴 꼬리), 소쩍새와 솔부엉이(서 있는 자세, 노란 눈).
- 물고기: 어름치(옆구리의 검은 점 줄), 감돌고기(굵은 검은 줄, 뾰족한 주둥이), 쏘가리(얼룩, 높은 등지느러미), 은어(아가미 뒤 노란 점), 피라미(푸른 줄), 참갈겨니(어두운 가로줄), 버들치(얼룩), 배스(옆구리의 얼룩 띠), 블루길(둥근 몸, 검은 귓바퀴, 주황 배).
- 짐승: 오소리(눈을 지나는 검은 줄), 노루(엉덩이의 흰 무늬, 큰 귀), 꽃사슴(흰 점, 가지 갈라진 뿔), 산양(흰 턱밑, 뒤로 휜 뿔), 멧토끼(긴 귀), 다람쥐(등의 줄 다섯 개), 청설모(풍성하고 큰 꼬리), 하늘다람쥐(날개막, 납작한 꼬리), 수달(굵고 긴 꼬리), 점박이물범(점무늬).
- 게: 농게(주황 큰 집게와 작은 집게. 가만히 있을 때 큰 집게를 흔든다), 달랑게(연한 모래색, 큰 눈자루), 엽낭게(작고 둥근 등딱지), 칠게(긴 눈자루).
- 풀: 위의 "풀과 자란 정도"를 본다.

## 움직임

`update(dt, t, mode)`가 내는 움직임이다.

| mode | 새 | 짐승 | 물고기 | 게 | 풀, 사람, 물범 |
|---|---|---|---|---|---|
| idle | 숨 쉬는 작은 움직임, 머리 돌리기 | 숨, 머리 돌리기, 귀 | 꼬리와 가슴지느러미 | 눈자루, 다리 떨림. 농게는 큰 집게 흔들기 | 풀은 바람에 흔들림. 사람은 머리 돌리기. 물범은 숨 |
| feed | 목을 내려 쪼기(땅에 닿도록 몸을 숙임) | 머리를 땅으로 내려 먹기 | 코를 숙임 | 집게를 번갈아 입으로 | 사람은 허리를 숙임. 물범은 머리를 내림 |
| alert | 목을 곧게 세움, 날개를 조금 듦, 둘러봄 | 머리와 귀를 세움, 꼬리를 듦 | 거의 멈추고 가슴지느러미를 폄 | 집게를 들고 몸을 높임 | 사람은 팔을 듦. 물범은 머리를 듦. 풀은 더 세게 흔들림 |
| move | 두 다리를 번갈아 걷기 | 대각선 걸음 | 크게 꼬리 치기 | 다리를 빠르게 움직임 | 사람은 걷기. 물범은 몸을 구부려 기기 |
| rest | 몸을 낮추고 목을 접음 | 몸을 낮춤 | 천천히 | 몸을 낮추고 눈자루를 접음 | 사람은 가만히 섬 |
| fly | 날개를 펴고 퍼덕임, 다리는 접거나 뒤로 뻗음 | 해당 없음 | 해당 없음 | 해당 없음 | 해당 없음 |

## 확인하지 못한 것

- 움직이는 모습은 정지 사진으로만 보았다. 걷기의 박자, 고개 흔들림의 부드러움, 풀의 흔들림, 날갯짓의 박자와 날개가 접히고 펴지는 과정은 움직이는 화면으로 보지 못했다.
- 게임 화면(`demo/`)에 넣어 보지 못했다. 게임의 빛, 안개, 그림자 아래에서 색이 어떻게 보이는지 모른다.
- 눈, 코, 몸의 비율은 사진 자료 없이 기억으로 그렸다. 닮은 정도는 확인하지 못했다.
- 종의 크기(위 표 전체)는 문헌으로 확인하지 않았다. 확인 필요.
- 생김새 가운데 다음은 확실하지 않아 확인이 필요하다.
  - 두루미: 목의 검은 부위 범위(지금은 목 윗부분과 얼굴만 검게 했다), 흰 뒷머리 줄은 넣지 않았다.
  - 넓적부리도요: 계절에 따른 깃(번식깃은 머리가 적갈색). 지금은 어두운 갈색 등과 흰 얼굴이다.
  - 저어새: 번식기의 노란 가슴 띠는 넣었고, 뒷머리 장식깃은 가늘게 넣었다. 계절을 구분하지 않았다.
  - 꽃사슴과 노루의 뿔: 수컷 기준으로 넣었다. 계절(뿔갈이)은 보지 않았다.
  - 농게와 칠게: 집게와 등딱지 색. 농게의 큰 집게는 한쪽(모형의 +X쪽)으로 정했고 실제로는 개체마다 좌우가 다르다.
  - 어름치, 감돌고기, 쏘가리 등 물고기의 지느러미 수와 모양, 점의 자리는 단순하게 줄였다.
  - 쇠기러기 배의 검은 얼룩, 솔부엉이 가슴의 줄무늬는 꼭짓점 색의 한계로 거칠게 나온다.
  - 산양의 몸 색, 점박이물범의 점 개수와 크기.
- 하늘다람쥐의 날개막은 접은 모양만 있고 펴지는 동작은 없다.
- 작은 모양(게 등)은 눈자루와 다리가 가늘어 멀리서는 안 보일 수 있다. 게임에서 키워서 쓸 때 다시 본다.
- 이동 방향으로 돌리거나 자리를 옮기는 일은 하지 않는다(게는 실제로 옆걸음이지만 모형은 앞으로만 선다).
