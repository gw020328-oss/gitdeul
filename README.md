# 깃들

사라져 가는 생명들이 깃드는 나만의 보호구역.

땅을 가꾸면, 실제 관찰 기록으로 배운 AI가 어떤 동물이 찾아올지 정하는 게임입니다.

## 처음 왔다면

1. [한 장 읽을거리](docs/깃들_한장_읽을거리.md)를 먼저 읽습니다. 10분이면 됩니다.
2. 더 자세한 내용은 [기획서](docs/깃들_기획서.md)에 있습니다.
3. 자료를 다룰 사람은 [자료 목록](data/자료_목록.md)을 봅니다.

## 폴더

| 폴더 | 무엇 |
|---|---|
| `docs` | 기획서와 읽을거리 |
| `data` | 자료 목록과 자료를 받는 스크립트. 원본은 올리지 않습니다 |
| `model` | 이웃이 오는지, 머무는지를 판단하는 모델 |
| `game` | 게임 화면과 규칙 |

## 자료 받기

원본은 4 GB가 넘어서 저장소에 없습니다. `data/scripts`의 스크립트로 받습니다. 계정이나 키가 필요 없는 것들입니다.

```bash
mkdir -p data_raw/worldcover data_raw/dem
bash data/scripts/pull_worldcover.sh data_raw/worldcover
bash data/scripts/pull_dem.sh data_raw/dem
```

나머지 스크립트의 쓰는 법은 각 파일 첫머리에 적혀 있습니다.

## 약속

- `main`에 바로 올리지 않고 브랜치에서 올립니다.
- 키와 비밀번호는 올리지 않습니다. `.env`에 두면 올라가지 않습니다.
- 자료 원본은 올리지 않습니다. 파일 하나가 100 MB를 넘으면 GitHub가 받지 않습니다.
